# EcoTrack — Systems Audit & Sustainability

EcoTrack is a sophisticated waste-management and sustainability auditing platform. It combines a high-performance "Emerald Dark" aesthetic with robust local data persistence to help users track, analyze, and optimize their environmental impact through a professional, kinetic interface.

## 🌿 Core Features

- **Dynamic Waste Logging**: A "Closed-loop" audit system for tracking material mass and classification.
- **Predictive Analytics**: Real-time calculation of CO₂ offset, water conservation, and material distribution.
- **Kinetic Interface**: Powered by Framer Motion, featuring glassmorphic components and staggered entrance animations.
- **Sustainability Intelligence**: A curated library of eco-tips designed for maximum environmental ROI.
- **Local Persistence**: Full functional integrity using `localStorage` for secure, client-side data auditing.

## 🛠️ Technical Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4 (Emerald-Dark Palette)
- **Animations**: Framer Motion
- **Icons**: Lucide React & Font Awesome Pro Integration
- **Typography**: Playfair Display (Serif) & Geist (Sans)
- **UI Components**: shadcn/ui (Built on top of Radix UI primitives for professional, accessible, and customizable components)

## 🚀 Getting Started

To run the project locally, install the required dependencies:

```bash
npm install framer-motion lucide-react clsx tailwind-merge shadcn/ui
```

Then, start the development server:

```bash
npm run dev
```

## 📊 Design Philosophy

EcoTrack utilizes an **Emerald Dark** design system, merging technical observability with organic aesthetics. The UI leverages `oklch` color spaces for vibrant accents, backdrop blurs for depth, and professional typography to deliver a premium, audit-grade user experience.
